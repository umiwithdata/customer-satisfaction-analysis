# Customer Satisfaction Analysis using R

## Project Overview

This project demonstrates a simple customer satisfaction analysis using R.

The objective is to analyze customer satisfaction across different smartphone brands using descriptive statistics and basic data visualization.

---

## Business Question

Which smartphone brand has the highest customer satisfaction?

---

## Dataset

- 200 synthetic survey respondents
- 5 smartphone brands:
  - Apple
  - OPPO
  - Samsung
  - vivo
  - Xiaomi

Variables include:

- Satisfaction
- Camera Rating
- Battery Rating
- Value for Money
- NPS Score
- Purchase Channel
- Repurchase Intention
